## 8. Before you publish — open questions

1. **Posted opening hours.** Section 2 is derived from door scans, not from an
   official schedule. Confirm, including whether Sunday is genuinely closed.
2. **Trainer consent.** Names, photos and bios are personal data. Get each
   trainer's agreement before putting them on a public page.
3. **Publish prices or not?** Everything above is accurate, but whether the
   fee table goes public is a commercial decision. Many gyms publish packages
   and withhold PT rates — the data supports either approach.
4. **Sports Arena / Gym Passport at Rs 50,000.** Nobody has documented what
   these include.
5. **Admission fee presentation.** Rs 15,000 on top of the first month is a
   significant number. Decide whether it's shown up front or at enquiry.
6. **Trainer photos and bios** — the main missing asset.
7. **No class timetable exists in the system.** If the site should show class
   schedules (Zumba, Pilates, CrossFit, MMA), that data has to be collected
   separately; nothing in the database holds it.
